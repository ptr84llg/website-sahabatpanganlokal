Kebijakan Privasi

Penjelasan singkat mengenai data pada website Sahabat Pangan Lokal.

01

Data di website

Website ini tidak menyediakan akun dan tidak meminta nama, email, sekolah, alamat, atau nomor telepon.

02

Jika ada perubahan

Jika cara website menggunakan data berubah, penjelasannya akan diperbarui di halaman ini agar mudah diketahui.

Informasi mengenai data yang digunakan oleh permainan akan dijelaskan sebelum tautan unduh tersedia.
