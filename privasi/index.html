Privasi

Kebijakan Privasi

Penjelasan singkat mengenai data pada website Sahabat Pangan Lokal.

01

Data saat unduhan dimulai

Website tidak menyediakan akun dan tidak meminta nama, email, sekolah, alamat, atau nomor telepon. Saat tombol Unduh Sekarang ditekan, website mencatat platform dan versi rilis, kategori perangkat, sistem operasi, browser, kualitas jaringan, serta waktu server untuk menghitung dan menjaga keandalan unduhan.

02

Lokasi perkiraan

Lokasi yang dapat dicatat hanya negara, wilayah, dan kota perkiraan dari infrastruktur jaringan. Lokasi ini tidak sama dengan alamat fisik dan dapat tidak tersedia atau kurang akurat pada jaringan tertentu.

03

Yang tidak disimpan

Database analytics tidak menyimpan IP mentah, GPS atau lokasi presisi, latitude/longitude, IMEI, MAC address, Android ID, serial perangkat, advertising ID, nama, email, maupun nomor telepon.

04

Waktu dan tujuan pencatatan

Waktu server menjadi waktu resmi untuk setiap peristiwa unduhan. Zona waktu browser hanya digunakan sebagai konteks. Data digunakan untuk statistik jumlah unduhan, pemantauan keandalan paket, kondisi koneksi, dan perbaikan pengalaman unduh.

Angka pada website menunjukkan jumlah unduhan yang dimulai, bukan jumlah orang unik dan bukan bukti bahwa pemasangan permainan telah selesai.
